# CrossLanguageWord
Cross-language crosswords

## Why?

We got a German crossword puzzle book for Christmas from friends to help us learn German. It is supposed to be one-a-day, but we've done one in seven months, because we first have to translate the questions, then solve them, then make sure we've spelled the answer right.

Having the clues in English and only requiring us to get the spelling correct in German, should bring down the "uggggh" factor enough for us to actually practice our German this way. We can always add German clues (either for English or German words) later.

That it's a computer program also means we can have it check if we answered correctly, which a paper puzzle won't do.
